🛡️ CyberSec Dashboard

Dashboard estático desenvolvido para simular uma interface de monitoramento de segurança de rede.

O projeto foi desenvolvido utilizando HTML5 e CSS3, com foco na construção de uma interface organizada, responsiva e inspirada em sistemas de monitoramento de cybersecurity.

📌 Funcionalidades
Dashboard de monitoramento de rede
Menu lateral de navegação
Cards com indicadores de status
Área de alertas de segurança
Indicadores visuais para diferentes estados
Efeitos de interação com hover
Layout responsivo para diferentes tamanhos de tela
🛠️ Tecnologias utilizadas
HTML5
CSS3
Flexbox
CSS Grid
Media Queries
📚 Conceitos praticados

Durante o desenvolvimento foram praticados conceitos como:

Estrutura semântica do HTML
Organização de páginas web
Classes e seletores CSS
Flexbox
CSS Grid
Responsividade
Pseudo-classe :hover
Transições CSS
Organização de componentes visuais
🎯 Objetivo

Este projeto faz parte do meu portfólio de estudos em desenvolvimento e cybersecurity, com o objetivo de praticar desenvolvimento web e criar interfaces relacionadas ao monitoramento de segurança de redes.
